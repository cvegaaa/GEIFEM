# GEIFEM — Sitio web

Sitio web corporativo de GEIFEM, con backend en Python y frontend en React.

## Qué resuelve

Presencia web de la empresa: información institucional, contacto vía WhatsApp y página de política de privacidad (requerida para la validación de la API de WhatsApp Business de Meta).

## Stack técnico

- **Backend:** Python + FastAPI, MongoDB (Motor), rate limiting con SlowAPI, desplegable en Railway/Render.
- **Frontend:** React + CRACO, desplegable en Netlify.
- **Tests:** suite de pruebas incluida en `backend/tests` y `tests/`.

## Estado

En producción.
